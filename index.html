About

Full stack on paper, backend at heart.

At Volvrit I build complete features on MERN stack products for clients: MongoDB schemas and Express REST APIs on the backend, React.js and Next.js screens on the frontend.

Recent work covers payments, background jobs, real-time tracking and access control. I owned the CafeCold backend, built a double-entry ledger for credit and GST invoicing, fixed duplicate orders in production with a database-level guard, and built an AI assistant on OpenAI function calling.

I care about the boring parts that keep production calm: indexes, atomic updates, queues for slow work, and TypeScript so type errors are caught before release.
